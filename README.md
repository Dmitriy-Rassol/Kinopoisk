# Кинотека

Каталог фильмов, сериалов и актёров на Vue 3 и TypeScript.
Данные загружаются из [PoiskKino](https://poiskkino.dev/).

## Возможности

- Каталог с фильтрами по типу и жанру, сортировкой по популярности, рейтингу или году и пагинацией.
- Поиск фильмов и персон с подсказками. У двух разделов результатов независимая пагинация.
- Страница фильма с постером, описанием, рейтингами Кинопоиска и IMDb, основными сведениями и актёрами.
- Всплывающие карточки актёров при наведении или фокусе: фото, биографические сведения, известные фильмы и переход к профилю.
- Страница персоны с биографией, фактами и фильмографией. Год выхода указан под названием фильма.
- Поиск внутри фильмографии и фильтр «Только актёрские роли».
- Графики количества работ и среднего рейтинга по годам, учитывающие фильтры фильмографии.
- Список «Буду смотреть»: добавление и удаление через сердечко, сохранение в браузере.
- Кастомные селекты с управлением клавиатурой и закрытием по Escape или клику снаружи.
- Скелетоны загрузки, сообщения об ошибках с повторным запросом, пустые состояния и адаптивная вёрстка.

## Технологии

Vue 3 (Composition API), TypeScript, Vite, Vue Router, Pinia, Axios и GSAP. Стили написаны на обычном CSS, графики — отдельным Vue-компонентом без библиотеки диаграмм.

## Быстрый старт

Требуются Node.js версии, соответствующей `^20.19.0 || >=22.12.0`, npm и API-ключ PoiskKino.

1. Установите зависимости из lock-файла:

   ```sh
   npm ci
   ```

2. Создайте файл `.env.local` на основе [.env.example](.env.example).

   PowerShell:

   ```powershell
   Copy-Item .env.example .env.local
   ```

   macOS / Linux:

   ```sh
   cp .env.example .env.local
   ```

   Если `.env.local` уже существует, отредактируйте его, не перезаписывая текущие настройки.

3. Замените `your_api_key` своим ключом:

   ```dotenv
   VITE_API_URL=https://api.poiskkino.dev/v1.4
   VITE_API_KEY=your_api_key
   VITE_PERSON_API_URL=https://api.poiskkino.dev/v1.5
   ```

4. Запустите сервер разработки:

   ```sh
   npm run dev
   ```

Откройте адрес из терминала Vite. После изменения переменных окружения перезапустите сервер.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Сервер разработки |
| `npm run type-check` | Проверка типов TypeScript и Vue |

Перед просмотром сборки выполните `npm run build`. Отдельный набор автоматических тестов в проекте пока не настроен.

## Страницы и навигация

| Адрес | Содержимое |
| --- | --- |
| `/` | Каталог и результаты поиска |
| `/movie/:id` | Страница фильма или сериала |
| `/person/:id` | Биография и фильмография персоны |
| `/watchlist` | Список «Буду смотреть» |
| Остальные адреса | Страница «Не найдено» |

Параметры каталога сохраняются в URL: `q`, `type`, `genre`, `sort`, `page` и `peoplePage`. Ссылку с текущим поиском или фильтрами можно сохранить или отправить. Поиск по запросу работает отдельно от фильтров каталога.

## API и данные

Запросы настроены в [src/api.ts](src/api.ts). Ключ передаётся в заголовке `X-API-KEY`, тайм-аут запроса — 15 секунд.

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `VITE_API_KEY` | Ключ доступа | Не задан |
| `VITE_API_URL` | API фильмов | `https://api.poiskkino.dev/v1.4` |
| `VITE_PERSON_API_URL` | API персон | `https://api.poiskkino.dev/v1.5` |

Используемые методы:

- Фильмы: `/movie`, `/movie/search`, `/movie/:id`.
- Персоны: `/person/search`, `/person/:id`.
- Годы выхода для фильмографии запрашиваются дополнительно через `/movie` группами идентификаторов.

Графики учитывают уникальные работы по идентификатору, включая фильмы и сериалы. Работы без года выхода не включаются в график; их количество выводится отдельно. Средний рейтинг рассчитывается только по работам с оценками. Нулевое значение рейтинга считается отсутствием оценки.

Данные всплывающей карточки актёра запрашиваются при первом открытии и сохраняются на время жизни компонента. Факты и описания ролей из API преобразуются в обычный текст.

### Список «Буду смотреть»

Pinia хранит текущее состояние, а `localStorage` — сохранённые фильмы под ключом `kinoteka.watchlist`. Список доступен в том же браузере и профиле; синхронизации между устройствами и авторизации нет. Если браузер запрещает запись, сайт показывает сообщение, а изменения остаются доступными до перезагрузки.

## Сборка и размещение

```sh
npm run build
npm run preview
```

Для статического размещения используйте содержимое `dist/`. Настройте хостинг так, чтобы прямые переходы на маршруты приложения, например `/person/123`, возвращали `index.html`: роутер использует History API.

Переменные `VITE_*` встраиваются в клиентскую сборку и доступны в браузере. Исключение `.env.local` из Git не скрывает ключ в опубликованном приложении. Если ключ должен оставаться приватным, нужен серверный прокси, который добавляет ключ на сервере; в текущем проекте такого прокси нет.

## Если что-то не работает

- **API отклоняет запрос:** проверьте ключ, адреса API и доступ к методам фильмов и персон.
- **Превышен лимит запросов:** повторите запрос позже; фильмография с большим количеством работ требует нескольких запросов.
- **Изменения в окружении не применились:** перезапустите Vite, а для публикации заново выполните сборку.
- **Прямая ссылка на фильм или актёра возвращает 404:** настройте возврат `index.html` на хостинге.
- **Не хватает постера, биографии или года:** эти поля могут отсутствовать у источника; интерфейс показывает доступные данные и заглушки.
