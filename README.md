# Кинотека

Каталог фильмов: Vue 3, TypeScript, Vite, Pinia, Vue Router и Axios.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Предоставленный API-ключ находится в локальном `.env.local`, исключённом из Git. Для другого окружения скопируйте `.env.example` в `.env.local` и укажите ключ.

```sh
npm run type-check
npm run build
npm run preview
```

## Возможности

- Каталог с пагинацией, фильтрами по типу и жанру, сортировкой.
- Поиск по названию; параметры каталога сохраняются в URL.
- Страница фильма с рейтингами, описанием и актёрами.
- Список «Буду смотреть» на Pinia с сохранением в localStorage.
- Адаптивный интерфейс, состояния загрузки, ошибок и пустых результатов.

## API

Источник: https://poiskkino.dev/. Axios использует заголовок `X-API-KEY`, базовый URL `https://api.poiskkino.dev/v1.4`, методы `/movie`, `/movie/search`, `/movie/:id`. URL можно изменить через `VITE_API_URL`. Поиск работает отдельно от фильтров каталога.

Переменные `VITE_*` доступны в браузере. Для публичного размещения с приватным ключом нужен серверный прокси, который хранит ключ на сервере и ограничивает запросы. При статическом размещении настройте перенаправление неизвестных путей на `index.html` для Vue Router.


## Актёры и персоны

Единый поиск одновременно находит фильмы и персон. Результаты показаны двумя блоками с независимой пагинацией; запрос и страницы сохраняются в URL. Страница `/person/:id` содержит фотографию, биографические сведения, факты и фильмографию с поиском и фильтром актёрских ролей. Имена актёров на странице фильма ведут к их профилям.

Персоны используют API v1.5: `/person/search` и `/person/:id`. При необходимости задайте `VITE_PERSON_API_URL`. Факты из API преобразуются в обычный текст без вставки стороннего HTML.
